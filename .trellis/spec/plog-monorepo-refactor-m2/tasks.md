## 🚀 开发流程

### 1. 环境准备
```bash
# 安装依赖
cd apps/admin-web
npm install

# 启动开发服务器
npm run dev
```

### 2. 开发规范
- 组件命名: PascalCase (如: PostList.vue)
- 文件命名: kebab-case (如: post-list.vue)
- 变量命名: camelCase
- 常量命名: UPPER_SNAKE_CASE
- CSS 类名: kebab-case

### 3. Git 提交规范
- feat: 新功能
- fix: 修复 bug
- docs: 文档更新
- style: 代码格式调整
- refactor: 重构
- test: 测试相关
- chore: 构建/工具相关

---

## 📝 注意事项

1. **API 对接**: 所有 API 请求需要携带 Token
2. **错误处理**: 统一使用 Element Plus Message 组件提示错误
3. **权限控制**: 每个路由和操作都需要验证权限
4. **性能优化**: 使用路由懒加载、组件按需加载
5. **安全考虑**: 敏感信息不要存储在 localStorage
