# 三态分离设计 - PRD

## 1. 概述

**任务名称**: 三态分离设计
**所属阶段**: Phase 1 - 边界收敛
**优先级**: P1 (重要)
**预计工时**: 1 周
**前置依赖**: 领域模型接口抽象完成

## 2. 背景

系统的核心架构需要明确区分开发态、构建态和运行态。这种分离有助于：
- 清晰的职责边界
- 更好的可维护性
- 更容易的 Rust 迁移

## 3. 目标

1. 分析现有代码，识别三态边界
2. 编写三态分离设计文档
3. 调整代码组织结构

## 4. 三态定义

| 状态 | 包含内容 | 说明 |
|------|----------|------|
| 开发态 | 源代码、测试、文档、配置模板 | 开发者日常工作 |
| 构建态 | 编译产物、构建配置、静态资源 | CI/CD 处理 |
| 运行态 | 服务进程、运行配置、数据文件 | 生产环境运行 |

## 5. 范围

### 包含

- 三态分析报告
- 三态分离设计文档
- 代码结构调整方案
- 配置文件分类

### 不包含

- 代码重构实施
- Rust 代码编写
- 构建系统改造
