# PHP 兼容层框架 - PRD

## 1. 概述

**任务名称**: PHP 兼容层框架
**所属阶段**: Phase 3 - 掏空 PHP
**优先级**: P0 (核心)
**预计工时**: 2 周
**前置依赖**: Phase 2 完成

## 2. 背景

Phase 2 完成 Rust 核心服务后，需要建立 PHP 兼容层框架，让 PHP 只做兼容入口，真实业务规则在 Rust。

## 3. 目标

1. 设计兼容层架构
2. 实现请求转发
3. 实现响应转换
4. 编写文档

## 4. 兼容层架构

```
┌─────────────────────────────────────────────────────────────┐
│                  PHP Compat Layer                            │
├─────────────────────────────────────────────────────────────┤
│                                                               │
│  ┌─────────────┐     ┌─────────────┐     ┌─────────────┐  │
│  │  PHP Entry  │────►│   Router    │────►│   Proxy     │  │
│  │  (入口)     │     │  (路由)     │     │  (转发)     │  │
│  └─────────────┘     └─────────────┘     └─────────────┘  │
│                                                     │        │
│                                                     ▼        │
│                                            ┌─────────────┐  │
│                                            │ Rust API    │  │
│                                            └─────────────┘  │
│                                                               │
└─────────────────────────────────────────────────────────────┘
```

## 5. 范围

### 包含

- PHP 兼容层框架
- 请求转发逻辑
- 响应转换逻辑
- 错误处理
- 文档

### 不包含

- Rust 服务实现
- 老插件兼容
- 老主题兼容

## 9. 调用流程

```
1. PHP 接收请求
2. PHP 解析请求
3. PHP 转发到 Rust API
4. Rust 处理业务逻辑
5. Rust 返回响应
6. PHP 转换响应格式
7. PHP 返回给客户端
```

## 10. 风险

| 风险项 | 影响 | 概率 | 应对措施 |
|--------|------|------|----------|
| 性能损失 | 中 | 高 | 优化转发逻辑 |
| 响应格式不兼容 | 中 | 中 | 完善转换逻辑 |
| 超时处理不当 | 中 | 中 | 配置合理超时 |
