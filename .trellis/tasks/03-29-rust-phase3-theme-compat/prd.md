# 主题兼容层 - PRD

## 1. 概述

**任务名称**: 主题兼容层
**所属阶段**: Phase 3 - 掏空 PHP
**优先级**: P0 (核心)
**预计工时**: 3 周
**前置依赖**: 插件兼容层完成

## 2. 背景

在迁移到 Rust 的过程中，需要保持老主题可渲染。建立主题兼容层来桥接 PHP 主题和 Rust 核心。

## 3. 目标

1. 分析现有主题系统
2. 设计渲染管线抽象
3. 实现 PHP 模板引擎适配
4. 实现 Rust 模板引擎
5. 编写迁移工具

## 9. 模板语法对比

| 功能 | PHP 语法 | Tera 语法 |
|------|----------|-----------|
| 变量 | `<?php echo $var; ?>` | `{{ var }}` |
| 条件 | `<?php if ($cond): ?>` | `{% if cond %}` |
| 循环 | `<?php foreach ($items as $item): ?>` | `{% for item in items %}` |
| 函数 | `<?php func($arg); ?>` | `{{ func(arg) }}` |

## 10. 风险

| 风险项 | 影响 | 概率 | 应对措施 |
|--------|------|------|----------|
| 模板语法不兼容 | 高 | 高 | 提供转换工具 |
| 性能损失 | 中 | 高 | 缓存和优化 |
| 功能缺失 | 中 | 中 | 扩展 Rust 引擎 |
