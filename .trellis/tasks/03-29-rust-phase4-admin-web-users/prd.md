# admin-web 用户管理 - PRD

## 1. 概述

**任务名称**: admin-web 用户管理
**所属阶段**: Phase 4 - 逐步退休 /admin
**优先级**: P0 (核心)
**预计工时**: 2 周
**前置依赖**: Phase 3 完成

## 2. 背景

Phase 4 的目标是逐步退休 /admin 旧页面。首先需要在 admin-web 中实现用户管理功能，然后才能下线 /admin 中的用户管理页面。

## 3. 目标

1. 实现用户列表页面
2. 实现用户详情页面
3. 实现用户创建/编辑页面
4. 实现角色管理页面
5. 实现权限管理页面

## 4. 页面清单

| 页面 | 路由 | 功能 |
|------|------|------|
| 用户列表 | /admin-web/users | 用户列表、搜索、筛选 |
| 用户详情 | /admin-web/users/:id | 用户详情、编辑、删除 |
| 用户创建 | /admin-web/users/create | 创建新用户 |
| 角色管理 | /admin-web/roles | 角色列表、创建、编辑 |
| 权限管理 | /admin-web/permissions | 权限列表、分配 |

## 5. 验收标准

## 8. API 集成

```
GET    /api/v2/users          # 获取用户列表
GET    /api/v2/users/:id      # 获取用户详情
POST   /api/v2/users          # 创建用户
PUT    /api/v2/users/:id      # 更新用户
DELETE /api/v2/users/:id      # 删除用户

GET    /api/v2/roles          # 获取角色列表
POST   /api/v2/roles          # 创建角色
PUT    /api/v2/roles/:id      # 更新角色
DELETE /api/v2/roles/:id      # 删除角色

GET    /api/v2/permissions    # 获取权限列表
POST   /api/v2/permissions    # 分配权限
```
