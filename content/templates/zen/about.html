关于本站

Plog 是一个使用 Rust + Vue 构建的现代博客系统。它追求简洁、高效和优雅，专注于内容创作与知识分享。

这个名字来源于 "P" (Personal / Publish) + "Log"，寓意个人日志与发布平台。

技术栈

🦀 Rust ⚡ Axum 🐬 MySQL 🌊 SeaORM 💚 Vue 3 📘 TypeScript 🎨 Element Plus 🐳 Docker

特性

  • 🚀 高性能 Rust 后端，极低资源占用
  • 📝 Markdown 写作，实时预览
  • 🏷️ 分类与标签管理
  • 🎨 多主题支持，一键切换
  • 🔌 插件化架构，灵活扩展
  • 🔒 JWT 认证，安全可靠
  • 🐳 Docker 一键部署
  • 📱 响应式设计，适配各种设备
