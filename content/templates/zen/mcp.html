MCP

Model Context Protocol — 连接 AI 与数据的标准协议

什么是 MCP？

MCP (Model Context Protocol) 是一个开放协议，为 AI 模型提供与外部数据源和工具交互的标准化方式。它让 AI 助手能够安全地连接到各种数据源、API 和工具，实现更强大的功能。

简单来说，MCP 就像是 AI 的"USB 接口"——一个统一的连接标准，让 AI 能够即插即用地访问各种资源。

核心概念

🔌
Server
MCP 服务端，提供数据源和工具的访问能力。每个 Server 暴露特定的能力（资源、提示、工具）。
📱
Client
MCP 客户端，运行在 AI 应用中，负责与 Server 建立连接并协商能力。
🛠️
Tools
Server 暴露的可调用函数，AI 模型可以通过 Tool 执行操作、查询数据。
📦
Resources
Server 提供的数据资源，如文件、数据库记录、API 响应等。
💬
Prompts
预定义的提示模板，帮助用户快速完成常见任务。
🔄
Transport
通信传输层，支持 stdio 和 SSE 两种模式，灵活适配不同场景。

🗄️

快速开始

1. 安装 MCP SDK：

npm install @modelcontextprotocol/sdk

2. 创建一个简单的 MCP Server：

import { McpServer } from '@modelcontextprotocol/sdk/server.js';
import { StdioServerTransport } from '@modelcontextprotocol/sdk/server/stdio.js';

const server = new McpServer({ name: 'my-server', version: '1.0.0' });

server.tool('hello', { name: z.string() }, async ({ name }) => ({
  content: [{ type: 'text', text: `Hello, ${name}!` }]
}));

const transport = new StdioServerTransport();
await server.connect(transport);

3. 在 AI 客户端中配置 MCP Server 连接即可使用。
