Agent Skill

AI Agent 技能定义与能力扩展框架

什么是 Agent Skill？

Agent Skill 是 AI Agent 的能力单元，定义了 Agent 可以执行的具体操作和交互方式。每个 Skill 封装了一组相关的功能，包括输入输出规范、执行逻辑和上下文管理。通过组合不同的 Skill，Agent 能够完成复杂的任务流程。

Skill 与 MCP 的关系：MCP 提供数据通道，Skill 定义行为模式。两者配合，让 Agent 既有"手"（MCP），也有"脑"（Skill）。

核心 Skill 类型

🔍
搜索 Skill
信息检索与知识查找能力。支持多源搜索、结果排序、相关性判断，为 Agent 提供实时信息获取能力。
核心 必需
📝
创作 Skill
内容生成与编辑能力。包括文章撰写、代码生成、文档编辑、格式转换等，是 Agent 的核心产出能力。
核心 必需
🧠
推理 Skill
逻辑推理与决策能力。支持多步推理、条件判断、策略选择，让 Agent 能够处理需要深度思考的任务。
核心 必需
💬
对话 Skill
自然语言交互能力。支持多轮对话、意图理解、上下文记忆、情感识别，实现流畅的人机交流。
核心 必需

扩展 Skill

💻
代码 Skill
代码编写、审查、调试与重构能力。支持多语言编程、项目结构理解、依赖分析、测试生成。
扩展 开发场景
📊
数据 Skill
数据分析与可视化能力。支持数据清洗、统计分析、图表生成、趋势预测，辅助数据驱动决策。
扩展 分析场景
🌐
浏览器 Skill
网页浏览与操作能力。支持页面导航、内容提取、表单填写、截图，让 Agent 能够操作 Web 应用。
扩展 自动化场景
📁
文件 Skill
文件系统操作能力。支持文件读写、目录管理、格式转换、批量处理，是 Agent 与本地系统交互的基础。
扩展 系统场景
🔗
API Skill
外部 API 调用能力。支持 REST/GraphQL 请求、认证管理、响应解析、错误处理，连接第三方服务。
扩展 集成场景
🎨
设计 Skill
UI/UX 设计辅助能力。支持设计稿分析、组件推荐、样式生成、可访问性检查。
规划中 设计场景

Skill 架构

一个标准的 Agent Skill 由以下部分组成：

  • 📋 Schema — 输入输出的 JSON Schema 定义，描述 Skill 接受的参数和返回的结果
  • ⚙️ Handler — 执行逻辑的实现，接收输入参数，调用底层能力，返回执行结果
  • 📌 Context — 上下文管理，维护 Skill 执行过程中的状态、记忆和环境信息
  • 🛡️ Guard — 安全守卫，校验输入、限制权限、防止越权操作
  • 📊 Telemetry — 可观测性，记录执行日志、性能指标和错误信息

Skill 与 MCP 协作

🤝
Skill + MCP Server
Skill 通过 MCP 协议调用外部 Server 提供的工具和资源。例如"代码 Skill"通过 MCP 调用 GitHub Server 操作仓库。
已实现
🔄
Skill 编排
多个 Skill 可以串联或并联执行，形成复杂的工作流。编排器负责调度、错误恢复和结果聚合。
开发中
🧩
Skill 市场
社区共享的 Skill 注册中心，开发者可以发布、发现和复用经过验证的 Agent Skill。
