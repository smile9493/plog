## 🔧 工作流程

### 1. 识别意图
根据用户输入的关键词，匹配对应的技能

### 2. 激活技能
调用匹配的技能，加载相关规范和文档

### 3. 召回上下文
- 读取项目相关文件
- 理解当前开发状态
- 加载相关配置

### 4. 执行任务
根据技能规范执行具体任务

## 🚀 开始使用

只需输入关键词，Agent会自动识别并激活对应技能！

例如：
- "开发一个plog插件" → 激活 plog-plugin-dev-skill
- "优化布局和间距" → 激活 arrange
- "添加动画效果" → 激活 animate
