项目审查清单模板
1. 需求审查
项目目标是否明确
需求是否完整、无歧义
是否存在需求蔓延
优先级是否清晰
验收标准是否明确
2. 架构审查
整体架构是否合理
模块边界是否清晰
是否高耦合、低内聚
扩展性是否足够
是否便于维护和重构
技术选型是否合适
3. 代码质量审查
代码风格是否统一
命名是否清晰
是否存在重复代码
逻辑复杂度是否过高
注释是否必要且准确
异常处理是否完善
是否存在坏味道代码
4. 安全审查
输入是否做校验
权限控制是否正确
敏感数据是否加密或脱敏
是否存在注入、越权、XSS、CSRF 等风险
依赖库是否有已知漏洞
日志是否泄露敏感信息
5. 性能审查
关键路径性能是否达标
是否存在明显瓶颈
数据库查询是否合理
缓存策略是否有效
并发处理能力是否足够
内存、CPU、IO 占用是否合理
6. 稳定性与可靠性审查
异常场景是否覆盖
是否有容错与降级方案
是否支持重试、熔断、限流
数据一致性是否有保障
是否存在单点故障
故障恢复能力如何
7. 测试审查
单元测试是否完整
集成测试是否覆盖核心流程
边界条件是否测试
回归测试是否可执行
测试覆盖率是否达标
是否有自动化测试
8. 部署与运维审查
构建流程是否稳定
发布流程是否规范
是否支持回滚
是否有监控、日志、告警
配置管理是否规范
环境差异是否可控
9. 文档与工程化审查
README 是否清晰
设计文档是否完整
API 文档是否可用
是否有开发规范
CI/CD 是否健全
分支管理、版本管理是否规范
10. 项目风险审查
是否依赖关键个人
是否有技术债务
进度是否可控
成本是否合理
后续维护风险是否高
外部依赖是否稳定
